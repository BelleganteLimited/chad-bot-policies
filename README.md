# Chad Bot policies and support

Public policies for the private, experimental Chad Bot Discord PAPER application.

- [Terms of Service](TERMS.md)
- [Privacy Policy](PRIVACY.md)
- [Support, privacy and deletion requests](https://github.com/BelleganteLimited/chad-bot-policies/issues/new)

This repository contains policy documents, not application source, trading signals, credentials or private source content. It does not establish Discord approval, operational readiness or investment performance.

**This support tracker is public.** Do not post credentials, account identifiers, private messages or charts. For a sensitive request, post only that you need private follow-up. The project will arrange a suitable private channel before asking for details.
